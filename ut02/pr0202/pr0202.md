# Práctica 2: Uso del cliente HDFS

1. **Preparación del entorno**
- Crea un directorio personal en HDFS bajo /user con tu nombre de usuario y dentro de él un directorio llamado proyecto_datos.

`hdfs dfs -mkdir -p /user/alejandro/proyecto_datos`
![Foto 1](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.05.05.png)
Nota: el parámetro -p sirve para crear también las subcarpetas de la carpeta principal

2. **Carga de datasets**
- Descarga el dataset Automotive Price Prediction Dataset que puedes obtener desde Kaggle y que contiene un dataset sintético con información y precio de 1000000 de vehículos de segunda mano
- Desde tu sistema local, sube al directorio proyecto_datos el dataset que has descargado.
  
`hdfs dfs -put vehicle_price_prediction.csv /user/alejandro/proyecto_datos`
![Foto 2](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.15.37.png)
  
3. **Exploración de datos**
- Visualiza el contenido del archivo directamente en HDFS.
- Obtén el número de líneas del dataset.

`hdfs dfs -cat /user/alejandro/proyecto_datos/vehicle_price_prediction.csv`
![Foto 3](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.21.46.png)

`hdfs dfs -cat /user/alejandro/proyecto_datos/vehicle_price_prediction.csv | wc -l`
![Foto 4](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.24.40.png)

4. **Organización del proyecto**
- Crea un subdirectorio procesados y otro backup dentro de tu carpeta de proyecto.
- Copia el archivo original a backup.
- Mueve el archivo original de proyecto_datos a procesados.

`hdfs dfs -mkdir /user/alejandro/proyecto_datos/procesados /user/alejandro/proyecto_datos/backup`

`hdfs dfs -cp /user/alejandro/proyecto_datos/vehicle_price_prediction.csv /user/alejandro/proyecto_datos/backup/`

`hdfs dfs -mv /user/alejandro/proyecto_datos/vehicle_price_prediction.csv /user/alejandro/proyecto_datos/procesados/`
![Foto 4](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.29.43.png)
Nota: uso -R en ls para que se vea todo el árbol de lo que he creado.

5. **Colaboración en el equipo**
- Crea un directorio compartido bajo /compartido (si no existe) y copia allí tu dataset para que otros puedan acceder.

`hdfs dfs -mkdir -p /compartido`

`hdfs dfs -cp /user/alejandro/proyecto_datos/procesados/vehicle_price_prediction.csv /compartido/`
![Foto 5](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.36.41.png)

6. **Recuperación de datos**
- Descarga a tu sistema local el archivo que está en el directorio procesados.

`hdfs dfs -get /user/alejandro/proyecto_datos/procesados/vehicle_price_prediction.csv ./vehiculos_recuperado.csv`
![Foto 6](../../img/Captura%20de%20pantalla%202026-10-21%20a%20las%2012.39.30.png)

7. **Control de accesos**
- Verifica los permisos de tus archivos.
- Cambia los permisos de un archivo de backup para que solo tú tengas acceso de lectura y escritura.

`hdfs dfs -chmod 600 /user/alejandro/proyecto_datos/backup/vehicle_price_prediction.csv`
![Foto 6](../../img/Captura%20de%20pantalla%202026-10-27%20a%20las%209.43.24.png)

8. **Mantenimiento**
- Elimina un archivo temporal que hayas subido por error a tu espacio en HDFS.

`hdfs dfs -rm /user/alejandro/archivotemporal.txt`
![Foto 7](../../img/Captura%20de%20pantalla%202026-10-27%20a%20las%209.47.58.png)
